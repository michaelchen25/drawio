PPTX Manual Conversion Guide

This MVP does not provide one-click PPTX export. Use SVG export, then convert the diagram inside Microsoft PowerPoint.

Recommended Path

  1. Open the diagram in the biomed flowchart editor.
  2. Choose File -> Export as -> SVG.
  3. Save the exported SVG file.
  4. Open Microsoft PowerPoint desktop app.
  5. Insert the SVG onto a slide.
  6. Right-click the SVG and choose Convert to Shape.

What to Expect

  • Standard ISO 5807 shapes usually convert best.
  • Custom biomed shapes may split into many pieces after conversion.
  • If you only need a report image, keep the SVG as-is.

Known Limits

  • This MVP does not provide one-click PPTX export.
  • PowerPoint on the web may not support the same editing workflow.
  • Desktop PowerPoint is recommended for the best conversion result.
Keep the original .drawio file in Microsoft 365 OneDrive for Business as the editable source of truth.
