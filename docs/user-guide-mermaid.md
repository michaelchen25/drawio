# Mermaid Import Guide

The editor keeps draw.io's native Mermaid import, so you can turn Mermaid text
into an editable diagram and then refine it with the normal canvas tools.

## Import a Mermaid Diagram

1. Prepare your Mermaid text in advance.
2. In the editor, choose `Insert -> Mermaid`.
3. Paste the Mermaid text into the dialog.
4. Confirm the import.
5. The generated diagram will appear on the canvas as editable draw.io cells.

## Recommended Workflow

1. Use Mermaid to draft the overall flow quickly.
2. Adjust labels, spacing, connectors, and page layout in the editor.
3. Replace generic shapes with the biomed libraries when you need ISO 5807 or
   domain-specific presets.

## Known Limits

- Mermaid import quality depends on Mermaid syntax validity.
- Imported layouts may still need manual cleanup.
- Mermaid is a starting point for the diagram, not a locked source of truth.

## Practical Recommendation

- Use Mermaid for text-first drafting.
- Switch to the biomed sidebar libraries for final review-ready diagrams.
- Save the final editable result as `.drawio` in Microsoft 365 OneDrive for
  Business.
